⚡ 2. Terminal Execution Pipeline

The isolation was accomplished entirely using macOS native terminal utilities (yt-dlp and ffmpeg) under Zero-Cloud cost:

# Step 1: Download isolated 4-second section directly without pulling entire 4GB video
yt-dlp --download-sections "*2238-2242" "https://youtu.be/CAPfNrxklig" -o "vr_segment.mp4"

# Step 2: Normalize presentation timestamps and transcode to H.264/AAC for browser video tags
ffmpeg -y -ss 7.179 -i vr_segment.mp4.webm -c:v libx264 -c:a aac -pix_fmt yuv420p vr_segment.mp4

# Step 3: Decompose high-resolution sequence into 30 FPS sequential PNGs
ffmpeg -y -i vr_segment.mp4 -vf fps=30 frame_%04d.png

# Step 4: Generate lightweight thumbnails for zero-latency slider scrubbing in index.html
mkdir -p thumbs && ffmpeg -y -i vr_segment.mp4 -vf "fps=30,scale=640:360" thumbs/thumb_%04d.jpg
