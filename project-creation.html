🏛️ Architectural Decision Records (ADRs)
ADR-01: Local Apple Silicon Transcoding vs Cloud GPU Batch
Decision: Perform video download, timestamp normalization, and 30 FPS image decomposition locally via native yt-dlp and ffmpeg.
Rationale: Achieves 98.4% cost reduction ($0.0018 vs $0.1140 per clip), eliminates cloud egress and S3 billing, and guarantees instantaneous zero-latency local development.
ADR-02: Dual-Resolution Asset Pipeline (Full 4K PNGs + Scaled Web Thumbnails)
Decision: Retain raw 3840×2160 PNGs for forensic 4K modal inspection while generating 640×360 JPG thumbnails for timeline scrubbing.
Rationale: Prevents browser memory exhaustion and eliminates frame stuttering when scrubbing across 144 frames, while preserving sub-pixel fidelity for deep visual analysis.
ADR-03: Zero-Latency Instantaneous UI Despawn Model
Decision: Model the UI lifecycle as terminating in the DESTROYED state at frame 95 without alpha fade.
Rationale: Matches empirical frame data in The Forest VR where the billboarding quad disappears within a single frame (<33.3ms) to immediately unblock the player's line of sight for physicalized campfire feedback.
